# AltAccounts 小号轮换

同一网易账号下不同区服的多个小号，按列表顺序逐个登录并执行琐事任务，
全部跑完后按配置决定是否切回主力角色。

## 用法

1. 「小号轮换设置」里填小号数量，保存后生成对应数量的小号条目；
2. 每个小号条目填 **角色名 + 区服名**（同一账号时「网易账号」可留空，
   若登录界面出现账号选择卡住再填）；
3. 在「每日琐事」「每周琐事」「地域鬼王」配置页设置具体要执行的项目与战斗设置（所有小号共用同一套开关）；
4. 调度里启用本任务并设置时间（默认每天一次，失败半小时后重跑）。

## 行为说明

- 每个小号每天只跑一次每日琐事，按条目里的「上次完成时间」判断；
- 每周琐事距上次完成满 6 天才再次执行（不固定周几，停机错过也不漏）；
- 地域鬼王按「上次完成地域鬼王」每天一次；0-6 点鬼王未刷新会跳过，调度请避开该时段；
- 每个小号的完成记录相互独立，执行时临时注入，不改动全局配置文件；
- 建议开启「跑完切回主力角色」，或关闭本配置里「每日琐事/每周琐事/地域鬼王」的独立调度，
  避免后续任务登录在小号上。
